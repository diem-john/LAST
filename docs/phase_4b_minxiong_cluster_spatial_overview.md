# Phase 4B — Minxiong Cluster Spatial Overview Map

## Purpose

This visualization provides a geographic comparison of all nine frozen
Minxiong analytical urban clusters (Q05), their surrounding mapped OSM road
features, and mapped OSM hospital polygons. Clusters 001, 002, and 009 are
highlighted as a preliminary review shortlist based on the descriptive
screening metrics. Highlighting is not a final selection or suitability score.

## Inputs

- `data/geospatial/processed/chiayi_analytical_urban_clusters.gpkg`,
  layer `analytical_urban_clusters`.
- `data/geospatial/raw/osm/roads/osm_chiayi_roads_edges.gpkg`,
  layer `osm_chiayi_roads_edges`.
- `data/geospatial/raw/osm/facilities/osm_chiayi_hospitals.gpkg`,
  layer `osm_chiayi_hospitals`.
- `reports/geospatial/minxiong_cluster_screening.csv`, generated by
  `scripts/screen_minxiong_clusters.py`.

All map layers are transformed to EPSG:3826 for display. The script validates
the required layers, geometries, nine-cluster count, and matching metrics.

## Run

From the repository root in the `agentic_ai` environment:

```powershell
python scripts/visualize_minxiong_clusters.py
```

Output:

`reports/geospatial/minxiong_cluster_spatial_overview.png`

Optional path overrides:

```powershell
python scripts/visualize_minxiong_clusters.py --clusters <path> --roads <path> --hospitals <path> --metrics <path> --output <path>
```

## Interpretation

- Cluster 001 is highlighted because it has the largest area and total clipped
  road length in the current screening table.
- Cluster 002 is highlighted as an area/road-density comparison candidate.
- Cluster 009 is highlighted because it has the highest clipped road-length
  density, despite its smaller area.
- The map displays spatial arrangement and mapped context; it does not
  calculate road travel times, electrical connectivity, population coverage,
  flood exposure, terrain suitability, or the six-criterion weighted score.
- OSM road and hospital coverage is unverified. A hospital marker represents
  a mapped OSM hospital polygon, not a verified complete healthcare inventory.
- The map is a visual review aid. A final cluster must not be selected solely
  from map appearance or these OSM proxy metrics.
- The enhanced IEEE 33-bus benchmark remains synthetic and
  Chiayi-georeferenced, not an actual Taipower feeder.
